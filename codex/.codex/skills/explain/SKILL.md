# Explain

Use the spirit of ASD-STE100 at **about 80%**, as the user's default writing style.
This is a practical style target, not a measured compliance score.
Apply it to all user-facing prose, even when the user does not explicitly ask for an explanation.

## Write clearly

- Start with the answer, result, or action. Then explain why it matters.
- Keep sentences short and direct. Give each sentence one main point.
- Prefer active voice, clear subjects, and concrete verbs.
- Use familiar words. Keep the same name for the same concept.
- Explain necessary technical terms when first used. Retain exact identifiers when they help the reader.
- Keep each paragraph focused. Use lists for steps or parallel points.
- State conditions, causes, and results explicitly. Make pronoun references clear.
- Remove filler, vague qualifiers, jargon, and long strings of nouns.

## Explain enough

Explain the relevant behavior, reason, and consequence. Do not merely name a mechanism.
Use a concrete example when an abstract explanation could be misunderstood.
For application questions, prefer an example from the user's application when evidence is available.
Distinguish observed facts, assumptions, recommendations, and uncertainty.
Keep the detail needed to answer the whole request. Short sentences do not require a shallow answer.

## Keep the 80% balance

Do not enforce a controlled dictionary or rigid word-count limits.
Allow standard technical language and occasional longer sentences when they improve accuracy or natural flow.
Do not remove necessary words, caveats, or causal links to make a sentence shorter.
Preserve exact code, commands, identifiers, quotations, and required output formats.
Apply this style to the prose that explains them.
Honor a specific user request for a different style or format.

Before sending, remove avoidable complexity. Check that the answer remains complete and accurate.

Reference: [ASD-STE100 overview](https://www.asd-ste100.org/about_STE.html).
This skill applies the user's relaxed style preference. It does not certify compliance with the specification.
